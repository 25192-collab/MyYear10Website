My Reflection

🎨 Image Creation

For the Image Creation unit, all of the designs featured on my site were my own original ideas. I brought these concepts to life using Inkscape to create clean vector artwork.

📦 3D Modeling

In 3D Modeling, I learned how to work in a three-dimensional digital space. I built my assets and environments using an application called Blender to model the shapes, apply textures, and render out the final scenes.

🎬 Animation

Much like the 3D modeling work, I used Blender to build my animations. To master the timeline, keyframes, and motion configurations, I followed a tutorial on YouTube to guide my learning process.

🛠️ Design & Manufacturing

During this engineering unit, the Voronoi bowl and the Lego block layouts were entirely my own original conceptual ideas. Additionally, I completely built the 3D house model entirely by myself from scratch using Fusion 360.

🎮 Video Game Development

For my platformer project, I initially followed a development tutorial provided by GDevelop to get the game's core framework functional. From there, I expanded the project by programming several custom features of my own to make the game unique.
